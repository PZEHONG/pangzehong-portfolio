# AI 视频展维护说明

2026-11-12 新增首页 `#ai-videos`，从用户指定的六个网站各选择五部，共 30 部。此展区是外部作品精选，每部保留来源作者与原作链接，不能作为本站作者的个人原创作品或商业成果。

## 内容与文件

- `assets/ai-videos.json`：30 部片单，包含作者、简介、类型、来源页、本地封面和播放方式。
- `assets/ai-video-gallery.js`：来源筛选、六部导览、展开全部、播放器及关闭释放。
- `assets/ai-video-gallery.css`：沿用作品集的明暗主题，适配新增的第五项导航。
- `assets/video-posters/`：28 张 WebP 和两张明确标为“作品题签”的 SVG。题签未伪造原片画面。

## 加载方案

默认导览显示每个来源一部，共六部。按来源显示五部；展开全部显示 30 部。接近展区时才请求片单，图片使用原生懒加载和固定比例避免跳动。全部封面合计 342,104 字节，六部导览封面合计 86,760 字节。压缩仅针对封面，没有复制、压缩或重新托管完整视频。

浏览、筛选、展开不会请求 MP4、播放清单或第三方播放器。点击后才创建当前的唯一播放器；原生视频使用 `preload=none`，关闭时暂停、清除地址并移除元素；YouTube iframe 同样仅在点击后创建，关闭时移除。

## 验证

先启动本地服务，再执行：

```sh
node scripts/verify-ai-videos.mjs
```

可传入站点地址作为第一个参数。检查覆盖每站五部、30 部唯一作品、本地封面体积、六个筛选、展开收起、浏览时零视频请求、九种宽度、实际原生播放、Escape、焦点恢复及关闭后的播放器释放。另检查了明暗主题截图和第三方原生视频元数据；原站可随时改变访问策略，后续失效时应更新片单或改为原站观看。
